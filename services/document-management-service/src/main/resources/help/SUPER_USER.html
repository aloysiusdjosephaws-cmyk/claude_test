Super User Help

As a Super User you have full administrative control over Application Managers and their Application assignments.

Managing Application Managers

  • Add an Application Manager by entering their details and clicking Add Manager.
  • Edit a manager's details by selecting them from the list and updating the form.
  • Delete a manager by selecting them and clicking Delete. This deactivates the account.

Assigning Applications

  • Select an Application Manager from the list.
  • Use the Assign Application panel to link one or more applications to that manager.
  • To remove an assignment, select the application in the manager's assignment list and click Remove.

Uploading Help Documents

  • Only Super Users can upload or replace help documents for any role screen.
  • Use the Help Management section to upload a new file (HTML or PDF recommended).

Audit Log

  • All create, update, and delete actions are recorded automatically in the Audit Log.
  • The audit log can be reviewed from the Audit tab.
All mutations (add, edit, delete, assign, unassign) are logged to the audit table with your user ID and timestamp.
