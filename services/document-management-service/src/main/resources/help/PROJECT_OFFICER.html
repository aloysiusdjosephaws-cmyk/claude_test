Project Officer Help

As a Project Officer you manage Applications, Application Users, and their assignments.

Managing Applications

  • Create a new application by entering a name and description, then clicking Add Application.
  • Edit an application by selecting it from the list and updating the form.
  • Delete an application by selecting it and clicking Delete.

Managing Application Users

  • Add an Application User by entering their details (username, name, email) and clicking Add User.
  • Edit a user's details by selecting them and updating the form.
  • Delete a user by selecting them and clicking Delete. This deactivates the account.

Assigning Applications to Users

  • Select an Application User from the list.
  • Use the Assign Application panel to link applications to that user.
  • To remove an assignment, select it and click Remove.
All create, update, delete, and assignment actions are recorded in the audit log with your user ID and timestamp.
