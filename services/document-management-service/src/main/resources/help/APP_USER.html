Application User Help

As an Application User you can search and download documents from your assigned applications.

Selecting an Application

  • Use the application dropdown to select one of your assigned applications.
  • Only applications assigned to you by a Project Officer are available.

Searching for Documents

  • Search by one or more of: Application ID, Key ID, Document Name, or Group.
  • Leave fields blank to retrieve all visible documents for the selected application.
  • Click Search to run the query.

Downloading Documents

  • Click the download icon next to any document in the results list.
  • The file will be saved to your default downloads folder.
Documents marked with a private file filter by the Application Manager are not visible to Application Users.
