Application Manager Help

As an Application Manager you upload and manage documents for your assigned applications.

Selecting an Application

  • Use the application list on the left panel to select the application you want to work with.
  • Only applications assigned to you are shown.

Uploading Documents

  • Click Upload Document and select a file from your computer.
  • Enter an optional description and assign the document to a Group.
  • File Filter (Y/N): Set to Y to make the document visible only to you. Set to N to make it visible to all users with access to this application.

Managing Documents

  • Edit: Update a document's description, group, or file filter setting.
  • Download: Click the download icon to save a document locally.
  • Delete: Removes the document from the list (soft delete).

Managing Groups

  • Groups help organise documents by category.
  • Create new groups using the Add Group option.
  • Assign documents to groups during upload or by editing an existing document.
All upload, update, and delete actions are recorded in the audit log with your user ID and timestamp.
